# HabitQuest

HabitQuest is a full-stack web application that turns daily habit tracking into a game.
Users create habits, mark them as completed each day, earn XP, build streaks, and level up.

## Problem and Target Users
Many students and young people struggle to keep daily habits because they lack motivation.
Game elements (XP, streaks, levels) make consistency more engaging.

## Features (planned)
- User registration and login (authentication)
- Personal habit management (create, read, update, delete)
- Daily habit completion with XP and streak calculation
- Profile page with level, XP, and streak statistics
- Input validation and error handling
- Responsive interface

## Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express (REST API)
- Database: to be decided (SQLite / MongoDB / PostgreSQL)
- Authentication: JWT
